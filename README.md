# 오아라이브 서비스 소개 페이지 리뉴얼 (whatsoa)

오아라이브 [서비스 소개 페이지](https://oalive.kr/whatsoa)를 새 디자인으로 다시 만드는 저장소예요.
관객과 아티스트에게 오아라이브를 한 페이지에서 소개하고, **관람**과 **아티스트 등록 문의**로 자연스럽게 이어지도록 하는 것이 목표예요.

## 소개

- **목적**: 공연 영상 플랫폼 오아라이브의 서비스(관람 방식, 내돈내보·WoW, 오뗌극장, 아티스트 지원)를 쉽게 알리고 이용으로 연결해요.
- **사용자**: 공연을 보러 오는 **관객**, 작품을 올리려는 **아티스트**
- **상태**: 디자인 완료 · 퍼블리싱 1차 완료 (이미지·확정 문구 반영 전)
- **회사**: 주식회사 필더필 (FillTheFeel Corp.)

## 시작하기

### 필요한 것

- 최신 브라우저(Chrome, Safari, Edge, Firefox)
- (선택) 로컬 서버를 띄울 Python 3 또는 Node.js — 빌드 도구는 필요 없어요.

### 설치와 실행

```bash
# 1. 저장소 받기
git clone https://github.com/hyozl/whatsoapage.git
cd whatsoapage

# 2. 환경 변수 (지금은 사용하지 않아요. 나중에 API를 붙일 때 사용)
cp .env.example .env

# 3. 로컬에서 보기
cd src
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 열기
```

`src/index.html`을 브라우저로 바로 열어도 대부분 동작해요. 폰트·이미지가 안 보이면 위처럼 로컬 서버로 열어 주세요.

## 문구·줄바꿈 고치는 법

문구는 모두 `src/index.html` 한 파일에 있어요. GitHub에서 파일을 열고 연필(Edit) → 수정 → **Commit changes**를 누르면 돼요.

| 쓰는 것 | 결과 |
|---|---|
| `<br />` | PC·모바일 **둘 다** 줄바꿈 |
| `<br class="pc" />` | **PC에서만** 줄바꿈 (모바일은 이어서 씀) |
| `<br class="mo" />` | **모바일에서만** 줄바꿈 (PC는 이어서 씀) |

예시: `내가 낸 돈은<br class="mo" /> 내가 본 작품에` → PC는 한 줄, 모바일은 두 줄.

- `<`, `>` 사이 글자(태그)는 지우지 말고, 그 바깥의 한글만 고쳐요.
- 보라색 영문 큰 제목(PAY AS YOU LIKE 등)은 웹에서는 글자라 바로 고칠 수 있지만, Figma에서는 그림이라 Claude에게 요청해요.
- Figma에서는 글자를 더블클릭 → `Shift + Enter`로 줄을 바꿔요. 코드와 같은 위치에서 바꿔 주세요.

## FAQ (고객센터 연동)

관객 FAQ 5개, 아티스트 FAQ 5개는 오아라이브 고객센터 FAQ(2026.11.20 기준)를 요약한 답변이에요.

- 각 답변의 **자세히 보기 →** 는 고객센터 원문 글로 연결돼요 (예: `/cs-center/user-faq/feature-watch/read/65`).
- **고객센터에서 더 보기 →** 는 관객은 `/cs-center/user-faq`, 아티스트는 `/cs-center/artist-faq` 로 가요.
- 고객센터 FAQ는 공개 API가 없어서 자동으로 불러오지는 않아요. 고객센터 글이 바뀌면 `src/index.html` 의 답변도 같이 고쳐 주세요. 이 페이지를 오아라이브 사이트(Next.js) 안으로 옮기면 사이트의 FAQ 데이터를 그대로 연결할 수 있어요.

## 오뗌극장 재생목록 (자동)

04 섹션 재생목록은 페이지를 열 때마다 **오아라이브 API에서 열린 오뗌 테마 3개를 무작위로** 불러와요.

- 주소: `https://api.oalive.kr/oatheme` (공개 API, 다른 사이트에서 불러와도 돼요)
- 썸네일: `https://api.oalive.kr/files/image` + `thumbnailPath`
- 항목을 누르면 오아라이브의 해당 테마 페이지가 새 탭으로 열려요.
- 불러오기에 실패하면 "오뗌극장 테마" 기본값 3개가 보여요.

## 오아라이브 디자인 가이드 (노션 "[필독] 디자인 가이드 모음")

이 페이지는 오아라이브 웹사이트 디자인 가이드를 따라요.

| 항목 | 규칙 |
|---|---|
| 색 | `--brand-color` #9450E7 · black #212121 · low #676767 · gray #979797 · border #D1D1D1 / #EDEDED · white #F7F7F7 · deep #6824D3 · light #C5A3E7 · pink #F61CD5 |
| 굵기 | 본문 400, 강조·제목 600 (그 외 굵기 쓰지 않음) |
| 섹션 제목 | 36px → 24px (540px 이하) |

| 본문 | 16px → 15px (540px 이하) · 데스크톱은 홀수 크기 쓰지 않음 |
| 기준 해상도 | 1000px (터치 기기) · 540px (스마트폰) |
| 좌우 여백 | 1000px 이하 20px |

## 작업 방식

- `main` 브랜치에 바로 올리지 않고, 작업 브랜치를 만든 뒤 **Pull Request**로 합쳐요.
- 브랜치 이름 예시: `design/...`(디자인 반영), `fix/...`(수정), `content/...`(문구·이미지 교체)
- 커밋 메시지는 무엇을 바꿨는지 한국어로 짧게 적어요. 예: `03 가격 슬라이더 최소 금액 수정`
- **디자인 변경은 항상 Figma 먼저** 고치고, 같은 내용을 코드에 반영해요. (Figma `서비스 소개` 페이지가 기준)

## 배포

아직 배포 전이에요. 정적 파일이라 `src/` 폴더를 그대로 올리면 돼요.

- 기존 사이트에 넣을 때: `src/index.html`의 `<main>` 안 섹션과 `css/style.css`, `js/main.js`를 현재 오아라이브 페이지 구조에 맞게 옮겨요. (헤더·푸터는 기존 것을 사용)
- 미리보기: `main`에 올리면 GitHub Actions(`.github/workflows/pages.yml`)가 `src/` 폴더를 GitHub Pages로 자동 배포해요. 처음 한 번 **Settings → Pages → Source를 "GitHub Actions"** 로 바꿔 주세요.
