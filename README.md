# 오아라이브 서비스 소개 페이지 리뉴얼 (whatsoa)

오아라이브 [서비스 소개 페이지](https://oalive.kr/whatsoa)를 새 디자인으로 다시 만드는 저장소예요.
관객과 아티스트에게 오아라이브를 한 페이지에서 소개하고, **관람**과 **아티스트 등록 문의**로 자연스럽게 이어지도록 하는 것이 목표예요.

## 소개

- **목적**: 공연 영상 플랫폼 오아라이브의 서비스(관람 방식, 내돈내보·WoW, 오뗌 극장, 아티스트 지원)를 쉽게 알리고 이용으로 연결해요.
- **사용자**: 공연을 보러 오는 **관객**, 작품을 올리려는 **아티스트**
- **상태**: 디자인 완료 · 퍼블리싱 1차 완료 (이미지·확정 문구 반영 전)
- **회사**: 주식회사 필더필 (FillTheFeel Corp.)

## 시작하기

### 필요한 것

- 최신 브라우저(Chrome, Safari, Edge, Firefox)
- (선택) 로컬 서버를 띄울 Python 3 또는 Node.js — 빌드 도구는 필요 없어요.

### 설치와 실행

```bash
# 1. 저장소 받기
git clone https://github.com/hyozl/whatsoapage.git
cd whatsoapage

# 2. 환경 변수 (지금은 사용하지 않아요. 나중에 API를 붙일 때 사용)
cp .env.example .env

# 3. 로컬에서 보기
cd src
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 열기
```

`src/index.html`을 브라우저로 바로 열어도 대부분 동작해요. 폰트·이미지가 안 보이면 위처럼 로컬 서버로 열어 주세요.

```

├── docs/
│   └── 오아라이브_서비스소개_리뉴얼_기획안.pdf   # 기획안

│   └── assets/
│       ├── fonts/              # OrdinaryArtist-Regular(영문), OrdinaryArtist-ico(아이콘)
│       ├── logo/               # 오아라이브 로고(보라·검정·흰색), A.N.D 어워드 2022

├── .env.example                # 환경 변수 예시 (실제 값은 .env에, 커밋 금지)
└── README.md
```

## 넣어야 할 이미지 (`src/assets/img/`)

Figma **`자료 · 캡처`** 페이지의 캡처를 PNG로 내보내 아래 이름으로 넣어 주세요. 파일이 없으면 기기 화면이 어두운 빈 화면으로 보여요.

|---|---|---|---|
| `watch-pc.png` | 관람하기 화면 (PC) | 1440×900 | 02 STEP 01 |
| `watch-mobile.png` | 관람하기 화면 (모바일) | 750×1624 | 02 STEP 01 |
| `detail-pc.png` | 작품 상세 화면 (PC) | 1440×900 | 02 STEP 02 |
| `detail-mobile.png` | 작품 상세 화면 (모바일) | 750×1624 | 02 STEP 02 |
| `oatheme-pc.png` | 오뗌 극장 화면 (PC) | 1440×900 | 02 STEP 03, 04 |
| `oatheme-mobile.png` | 오뗌 극장 화면 (모바일) | 750×1624 | 02 STEP 03, 04(모바일) |

> 로그인이 필요한 화면(WoW 결제, 아티스트 관리, 채팅)은 캡처하지 않고, 필요한 경우 설명용 그림으로 대신해요. 캡처할 때는 개인정보·결제 정보를 꼭 가려 주세요.

## 작업 방식

- `main` 브랜치에 바로 올리지 않고, 작업 브랜치를 만든 뒤 **Pull Request**로 합쳐요.
- 브랜치 이름 예시: `design/...`(디자인 반영), `fix/...`(수정), `content/...`(문구·이미지 교체)
- 커밋 메시지는 무엇을 바꿨는지 한국어로 짧게 적어요. 예: `03 가격 슬라이더 최소 금액 수정`
- 디자인이 바뀌면 Figma를 먼저 고치고, 같은 내용을 코드에 반영해요.

## 배포

아직 배포 전이에요. 정적 파일이라 `src/` 폴더를 그대로 올리면 돼요.

- 기존 사이트에 넣을 때: `src/index.html`의 `<main>` 안 섹션과 `css/style.css`, `js/main.js`를 현재 오아라이브 페이지 구조에 맞게 옮겨요. (헤더·푸터는 기존 것을 사용)
- 미리보기용: GitHub Pages에서 `src/` 폴더를 배포 대상으로 지정해 확인할 수 있어요.
